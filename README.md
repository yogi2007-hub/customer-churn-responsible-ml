# Responsible Customer Churn Project

A learning exercise exploring a responsible approach to customer churn prediction.

## Files

- `data-card.md` — dataset purpose, features, quality limits, and evaluation plan.
- `problem-framing-memo.md` — the decision, prediction target, and non-ML baseline.
- `risk-register.md` — possible harms and safeguards.
- `baseline.ipynb` — majority-class baseline using the sample’s class counts.

## Main limitation

The supplied sample has only 12 customers. The baseline is for demonstration only and does not show how a model would perform on new customers. The dataset’s source and sharing permission are unknown, so customer-level rows are not included here.
