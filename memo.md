# Responsible Customer Churn Project

This project explores whether customer activity can help identify customers who may leave a service. The supplied dataset has only 12 records, so this is a learning exercise—not a model ready for real customer decisions.

## Intended use

A future, properly validated model could help a support team prioritize optional, helpful outreach. Predictions should not be used to deny service, change prices, or penalize customers.

## Project files

- `data-card.md` — dataset details, limitations, risks, and evaluation plan.
- `memo.md` — problem framing and proposed decision process.
- `risk-register.md` — risks and safeguards.
- `baseline.ipynb` — planned baseline analysis.

## Data privacy

The dataset’s sharing permission is unknown. Customer-level data is not included in this repository.

## Limitations

The sample contains only 12 customers. Any results would be highly uncertain and for demonstration only.
